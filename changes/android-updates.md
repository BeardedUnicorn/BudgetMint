- BudgetMint for Android updates itself. It checks GitHub for a new release when it opens and once a day, as the desktop does, and asks before downloading it. It shows how far the download is, then opens Android's installer, which asks before replacing the app (the first time, Android also asks to let BudgetMint install apps). You stay signed in. If the download fails, Open in browser hands it to the browser. Settings → Updates checks now, or turns the automatic check off. Install this release by hand once, from the release page; later ones arrive in the app.
- On an Android phone with Advanced Protection on, which blocks apps from outside Google Play, the update dialog shows the steps to turn it off, with a button to the phone's Security settings, and offers the download once it's off.
